Noi dung chinh:

Cach cap nhat:
1. Ghi de source moi len source cu.

3. Neu can build lai:
   npm install
   npm run build
4. Neu dang chay service Windows thi restart service.
5. Sau khi cap nhat, xoa cache trinh duyet/PWA de nhan CSS moi.
