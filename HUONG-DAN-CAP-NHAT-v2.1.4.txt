BAN CAP NHAT v2.1.4

Noi dung chinh:
- Xe 16 cho duoc lam to hon xe 7 cho.
- Bo sung duong ao va vet chay duoi xe.
- Chu "Dang nhap van hanh" tren mobile duoc lam noi bat hon.

Cach cap nhat:
1. Ghi de source moi len source cu.
2. Chep lai file .env cu neu dang trien khai production.
3. Neu can build lai:
   npm install
   npm run build
4. Neu dang chay service Windows thi restart service.
5. Sau khi cap nhat, bat buoc tai lai manh Ctrl + F5 hoac xoa cache/PWA de nhan CSS moi.
