BAN CAP NHAT v2.2.0

Noi dung chinh:
- Nang cap giao dien theo tung bo phan.
- Them khoi bao mat va phan quyen ro rang hon.
- Them giam sat vi tri xe dang chay.
- Driver tu cap nhat vi tri GPS dinh ky khi dang di chuyen.
- Them nut lam moi du lieu de cap nhat nhanh cho lanh dao.

Cach cap nhat:
1. Ghi de source moi len source cu.
2. Chep lai file .env cu neu dang trien khai production.
3. Neu can build lai:
   npm install
   npm run build
4. Neu dang chay service Windows thi restart service.
5. Sau khi cap nhat, xoa cache trinh duyet/PWA de nhan giao dien moi.
