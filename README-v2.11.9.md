## Cập nhật

Copy đè `src/` và `public/` vào full source hiện tại (đã có v2.11.8 hoặc mới hơn), sau đó chạy:

```cmd
npm.cmd run verify:source
npm.cmd run check
npm.cmd run build
```

Không cần SQL và không cập nhật Navicom Gateway.
